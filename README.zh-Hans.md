[lailai.one](https://lailai.one) 通过 [giscus](https://giscus.app) 使用的 GitHub
Discussions 评论后端。

## 用途

💬 **评论存储** —— giscus 将网站页面映射为本仓库中的 GitHub Discussions。

🔐 **GitHub 身份** —— 读者使用 GitHub 登录；本仓库不保存应用密码或自建账号数据库。

🧹 **不存应用代码** —— 网站源代码与 giscus 集成配置属于网站仓库。本仓库仅用于讨论
数据与评论管理。

## 管理

在仓库的 **Discussions** 页面审核、回复、锁定或移除评论。issue 仅用于仓库级配置问题，
不用于文章回复。
